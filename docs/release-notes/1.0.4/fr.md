### Nouveautés

- **Attente pendant les vidéos et les appels.** L’activation en cas d’inactivité attend désormais tant qu’une vidéo, un appel, une présentation, un jeu ou un enregistrement d’écran maintient l’écran allumé, comme le verrouillage par inactivité de macOS. Les outils qui empêchent la mise en veille, comme `caffeinate` et Amphetamine, ne retardent pas le masque. Pour désactiver ce comportement, utilisez **Attendre pendant les vidéos et les appels** dans **Réglages > Masque d’écran**.
- **Avertissement hors ligne.** Tant que le Mac n’a pas de connexion réseau, « Hors ligne » s’affiche en rouge dans le coin supérieur droit du masque : vous savez ainsi pourquoi une tâche s’est arrêtée sous le masque.
- **Tentatives de code incorrectes.** Le pavé numérique indique combien de codes incorrects ont été saisis depuis l’activation du masque : vous savez ainsi si quelqu’un a essayé.

### Corrections

- **Rechercher des mises à jour** est désormais grisé dans le menu lorsqu’une recherche est déjà en cours.
- La définition d’un code ne risque plus de faire perdre le précédent si le trousseau refuse la modification.
