### 新機能

- **Touch ID で解除。** Touch ID 搭載の Mac では、キーパッドの表示中にセンサーに指を置くとマスクがオフになります。この Mac のロック解除に使う指紋を使い、キーを押しても何も起きません。オフにするには、**設定 > パスコード**の **Touch ID で解除**を切ります。指紋が何度も認識されず macOS が Touch ID をロックした場合は、設定にその旨が表示され、Mac のパスワードを入力すると再び使えます。それまではパスコードで解除してください。

### 修正

- アップデートの自動確認が、マスクがオフになった後に行われるようになりました。以前は、マスクがオンの間に予定された確認が丸一日スキップされたため、毎日同じ時刻にマスクをオンにする Mac ではアップデートが確認されませんでした。
