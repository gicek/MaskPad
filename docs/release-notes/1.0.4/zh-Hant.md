### 新增

- **視訊和通話期間等待。** 影片、通話、簡報、遊戲或螢幕錄製讓顯示器保持喚醒時，閒置自動開啟會等待，與 macOS 的閒置鎖定一致。`caffeinate`、Amphetamine 這類保持喚醒的工具不會延後遮罩。如需關閉，請在**設定 > 螢幕遮罩**中關掉**視訊和通話期間等待**。
- **離線提示。** Mac 沒有網路連線時，遮罩右上角會顯示紅色的「離線」，方便你知道遮罩下的工作為什麼停了。
- **密碼輸錯次數。** 數字鍵盤會顯示遮罩開啟以來密碼輸錯了多少次，有人試過你就能知道。
