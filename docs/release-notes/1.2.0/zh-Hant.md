### 新增

- **遮罩上顯示正在播放的內容。** 右上角的卡片會顯示目前的歌曲或影片，包括封面、播放進度和播放控制按鈕。瀏覽器和影片播放器只提供播放/暫停，避免在遮罩上把視窗切到別的影片。新安裝時預設開啟；本次更新後保持關閉，因為它會把正在播放的內容展示給 Mac 前的任何人，如需使用，請在**設定 > 螢幕遮罩**中打開**顯示正在播放**。也可以只隱藏控制按鈕。
- **設定介面重新設計。** 設定改為側邊欄佈局，分為一般、螢幕遮罩、解鎖與安全、整合和關於，並新增遮罩預覽，會隨留言和媒體選項即時變化。
- **可選擇 MaskPad 的語言。** 在**設定 > 一般**中選擇，可與 macOS 的語言不同，切換後立即生效。
- **重置密碼前會先確認**，並說明會有哪些變化。

### 修正

- 打開另一份 MaskPad（例如放在其他資料夾裡的副本）時，現在會在已執行的那份中打開設定，不會再同時執行兩份。
