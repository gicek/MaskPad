### Neu

- **Mit Touch ID entsperren.** Auf einem Mac mit Touch ID schaltet ein Finger auf dem Sensor die Maske aus, solange das Ziffernfeld angezeigt wird. Verwendet werden die Fingerabdrücke, die den Mac entsperren; ein Druck auf die Taste bewirkt weiterhin nichts. Zum Ausschalten dient **Mit Touch ID entsperren** in **Einstellungen > Code**. Sperrt macOS Touch ID nach zu vielen nicht erkannten Fingerabdrücken, weisen die Einstellungen darauf hin, und du kannst dein Mac-Passwort eingeben, um es wieder zu verwenden; bis dahin entsperrst du mit dem Code.

### Behoben

- Die automatische Suche nach Updates läuft jetzt, nachdem die Maske ausgeschaltet wurde. Bisher wurde eine Suche, die bei aktiver Maske fällig war, einen ganzen Tag lang übersprungen – ein Mac, der jeden Tag zur selben Zeit maskiert war, suchte daher nie nach Updates.
