### New

- **In-app updates.** MaskPad checks for updates once a day and can install them for you. Turn
  automatic checks off, see the version, or check right away in **Settings > General**, or choose
  **Check for Updates** from the menu bar icon. Updates never check or relaunch while the mask is on.
- **DMG download.** MaskPad now comes as a disk image: open it and drag MaskPad to Applications.
