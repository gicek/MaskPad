# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive in issues, pull requests and discussions; no harassment,
personal attacks or discrimination of any kind.

To report unacceptable behavior, contact the maintainer through their
[GitHub profile](https://github.com/gicek). Reports are handled confidentially, and the maintainer may
remove comments or block accounts that break these rules.
