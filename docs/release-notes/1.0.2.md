### New

- **Turn the mask on from other apps.** `maskpad on` in Terminal or the `maskpad://on` link covers the
  screen, so a script, an AI agent or a launcher can turn the mask on, for example when a long task
  starts. Nothing can turn it off except the passcode. Install the `maskpad` command from
  **Settings > General**.

### Improved

- **Hot corners no longer fire under the mask.** The pointer stops just short of the screen corners,
  so a hot corner can't open Mission Control or lock the Mac and interrupt what runs underneath.
- **Only a person can use the keypad.** Clicks and presses from background tools, such as Computer Use
  agents, are ignored, so they can't enter digits, start the wrong-passcode cooldown or lock the Mac.
  Mouse, trackpad, touch screen, keyboard and Screen Sharing still work.

### Fixed

- A correct passcode no longer fails once after another app came to the front under the mask.
