### Nouveautés

- **Déverrouiller avec Touch ID.** Sur un Mac doté de Touch ID, posez un doigt sur le capteur quand le pavé est affiché pour désactiver le masque. Ce sont les empreintes qui déverrouillent le Mac, et appuyer sur la touche ne fait toujours rien. Pour désactiver ce comportement, utilisez **Déverrouiller avec Touch ID** dans **Réglages > Code**. Si macOS verrouille Touch ID après trop d’empreintes non reconnues, les Réglages l’indiquent et vous permettent de saisir le mot de passe du Mac pour l’utiliser à nouveau ; d’ici là, utilisez le code.

### Corrections

- La recherche automatique de mises à jour a désormais lieu une fois le masque désactivé. Auparavant, une recherche prévue pendant que le masque était actif était sautée pendant une journée entière : un Mac masqué à la même heure chaque jour ne recherchait jamais de mises à jour.
