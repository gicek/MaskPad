### Novedades

- **Desbloquear con Touch ID.** En un Mac con Touch ID, apoya un dedo en el sensor mientras se muestra el teclado numérico para desactivar la máscara. Usa las huellas que desbloquean el Mac, y pulsar la tecla sigue sin hacer nada. Para desactivarlo, usa **Desbloquear con Touch ID** en **Ajustes > Código**. Si macOS bloquea Touch ID tras demasiadas huellas no reconocidas, Ajustes lo indica y te permite introducir la contraseña del Mac para volver a usarlo; mientras tanto, usa el código.

### Correcciones

- La búsqueda automática de actualizaciones ahora se hace cuando la máscara se desactiva. Antes, una búsqueda prevista con la máscara activa se saltaba un día entero, así que un Mac con la máscara activa a la misma hora cada día nunca buscaba actualizaciones.
